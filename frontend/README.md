# Frontend

## Commands

| Command            | Description                                    |
|--------------------|------------------------------------------------|
| `npm run dev`      | Start the dev server                           |
| `npm run build`    | Typecheck, then build into `../backend/public` |
| `npm run preview`  | Serve the last production build                |
| `npm run lint`     | Lint                                           |
| `npm run lint:fix` | Lint and autofix                               |
| `npm run check`    | `lint:fix` + `build`                           |
| `npm run deploy`   | Build and deploy hosting to the remote project |
